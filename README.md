# Profile Card UI Design 👤✨

A modern, clean, and responsive **Profile Card UI** built using **pure HTML and CSS**.  
This project is designed for beginners who want to practice **UI design, layout structuring, and styling**.

---

## 📌 Project Overview

This profile card displays personal information along with social media links and engagement stats.  
It is suitable for:
- Personal portfolio
- Beginner UI practice
- Resume / GitHub showcase
- HTML–CSS learning projects

---

## 🚀 Features

✔ Clean and modern UI  
✔ Responsive card layout  
✔ Circular profile image with border  
✔ Social media icons using Boxicons  
✔ Follow & Message buttons  
✔ Analytics section (Likes, Comments, Shares)  
✔ Beginner-friendly code structure  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Google Fonts (Poppins)**
- **Boxicons CDN**
